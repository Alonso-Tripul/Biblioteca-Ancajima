# Alcance del starter

Este commit deja preparado el proyecto desde cero para comenzar la práctica:

- módulos shared y androidApp;
- targets Android e iOS en el módulo compartido;
- paquete raíz pe.edu.upeu.bibliomobil;
- tema visual inicial propio;
- destino de navegación como referencia;
- carpetas de dominio, datos, DI y presentación.

La implementación de reglas de negocio, persistencia, casos de uso, estados, ViewModels, pantallas finales y pruebas corresponde al estudiante.
